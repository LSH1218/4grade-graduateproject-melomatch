## 📌 프로젝트 개요

**MeloMatch**는 **컴퓨터 비전**, **자연어 처리**, **음성 분석**을 결합한 멀티모달 감정 인식 기술을 기반으로 사용자의 현재 감정 상태를 정밀하게 분석하고, 그에 맞는 음악을 추천하거나 AI가 직접 작곡하는 개인 맞춤형 음악 추천 시스템입니다.

**2024년 동양미래대학교 자동화공학과 졸업 프로젝트**로 개발되었으며, 실시간 감정 분석과 음악 생성을 통해 사용자에게 정서적 만족과 감정적 공감을 제공하는 혁신적인 솔루션을 제안합니다.

### 🎯 핵심 가치

- **멀티모달 감정 인식**: 얼굴 표정, 음성, 텍스트를 동시에 분석하여 정밀한 감정 파악
- **실시간 처리**: 웹캠과 마이크를 통한 즉각적인 데이터 수집 및 분석
- **개인화된 음악 경험**: 나이, 성별, 감정 상태에 최적화된 음악 추천
- **AI 작곡**: 감정에 맞춘 실시간 MIDI 음악 생성
- **사용자 피드백 학습**: 지속적인 가중치 조정으로 추천 정확도 향상

## 🌟 주요 기능

### 1️⃣ 멀티모달 감정 분석
- **얼굴 인식** (DeepFace + MTCNN): 나이, 성별, 얼굴 표정 기반 감정 추출
- **음성 분석** (Wav2Vec2): 음높이, 음량, 템포 등 음향적 특징으로 감정 분류
- **텍스트 분석** (KcELECTRA): 음성을 텍스트로 변환 후 7가지 감정 분류
  - 감정 카테고리: 행복(happy), 슬픔(sad), 화남(angry), 중립(neutral), 놀람(surprise), 두려움(fear), 혐오(disgust)

### 2️⃣ 가중치 기반 감정 통합
```
최종 감정 = (텍스트 감정 × 0.8) + (음성 감정 × 0.2)
```
- 텍스트 모델의 높은 안정성을 기반으로 주 역할 부여
- 음성 모델은 미묘한 감정 신호 보완
- **단일 모델 대비 12% 정확도 향상**

### 3️⃣ YouTube 음악 추천
- YouTube Data API 활용
- 감정 + 나이대별 맞춤 검색어 자동 생성
- Selenium을 통한 자동 재생
- **사용자 만족도 85% 이상**

### 4️⃣ AI 음악 작곡
- MIDIUtil 기반 실시간 MIDI 작곡
- 감정별 악기, 템포, 스케일 자동 매핑
- 예시:
  - **행복**: 피아노, 바이올린 / 장조(C Major) / 120-140 BPM
  - **슬픔**: 첼로, 플루트 / 단조(A Minor) / 60-80 BPM
  - **화남**: 전자기타, 드럼, 베이스 / 단조(E Minor) / 140-160 BPM

### 5️⃣ 피드백 기반 학습
- 사용자 만족도 입력 → 감정별 가중치 자동 조정
- 긍정 피드백: +0.1 증가
- 부정 피드백: -0.1 감소
- JSON 파일에 저장되어 지속적 학습

## 🏗️ 시스템 아키텍처

### 핵심 기술 구조

![Core Technology](./assets/core-technology.png)

시스템은 3계층 구조로 설계되었습니다:

1. **자연어 처리** (상단): 사용자의 목소리를 인식해 감정을 분석
2. **음악 추천 과 AI음악 생성** (중단): 인식된 데이터에 맞는 음악 선별 및 생성
3. **컴퓨터 비전을 활용한 얼굴인식** (하단): 사용자의 얼굴을 인식하여 성별, 나이 인식

### 전체 시스템 구조도

![System Architecture](./assets/system-architecture.png)

#### 시스템 구성 요소

시스템은 크게 **4개의 주요 모듈**로 구성됩니다:

**1️⃣ 입력부 (Input Module)**
- 👥 **사용자**: 웹캠과 마이크를 통한 데이터 입력
- 🎤 **음성 수집**: 실시간 음성 녹음
- 📷 **영상 수집**: 실시간 얼굴 인식

**2️⃣ 메인 모듈 (Main Processing Module)**
- 🖥️ **노트북**: 중앙 처리 장치
- 📊 **데이터 처리**:
  - Kaggle: 학습 데이터셋
  - Python: 데이터 전처리
  - TensorFlow: 딥러닝 모델 학습
  - Selenium: 웹 자동화
- 🔄 **이미지 처리와 감정 및 나이 분석**: 
  - OpenCV, DeepFace
  - 나이, 성별, 감정 추출

**3️⃣ API 모듈 (API Module)**
- 🎬 **YouTube API**: 음악 검색 및 추천
- 🗣️ **Google Cloud Speech-to-Text**: 음성 → 텍스트 변환
- ☁️ **데이터 통신**: 클라우드 기반 실시간 처리

**4️⃣ 출력부 (Output Module)**
- 🎵 **음악 재생**: YouTube 음악 또는 AI 작곡 MIDI
- 🔊 **스피커**: 오디오 출력

#### 데이터 흐름 (상세)

```
사용자 입력 (얼굴 + 음성)
    │
    ▼

    ▼

    │

    ▼

```

### 데이터 흐름

1. **입력**: 웹캠 → 얼굴 이미지 / 마이크 → 음성
2. **전처리**: 
   - 음성 → Google STT → 텍스트
   - 이미지 → 224×224 정규화
   - 음성 → MFCC 특징 추출
3. **분석**: 
   - DeepFace: 나이(6개 구간), 성별, 감정
   - Wav2Vec2: 7가지 감정 확률
   - KcELECTRA: 7가지 감정 확률
4. **통합**: 가중치 기반 최종 감정 계산
5. **출력**: YouTube 추천 또는 AI 작곡 → 재생

#### 1. 나이 예측 모델
- **모델**: VGG16 (전이 학습)
- **데이터셋**: UTKFace
- **분류**: 6개 연령대 (0-9세, 10-19세, 20-29세, 30-39세, 40-59세, 60세 이상)

#### 2. 성별 예측 모델
- **모델**: VGG16 (전이 학습)
- **데이터셋**: UTKFace
- **분류**: 2개 클래스 (남성, 여성)
- **정확도**: 90% 이상
- **손실 함수**: Binary CrossEntropy
- **특징**: Dropout 레이어로 과적합 방지

#### 3. 텍스트 감정 분석 모델
- **모델**: KcELECTRA (한국어 특화)
- **데이터셋**: AIHub 감정 데이터셋 (단발성 + 연속적 문장 통합)
- **분류**: 7개 감정
- **정확도**: 약 65%
- **전처리**: 오버샘플링으로 데이터 불균형 해결

#### 4. 음성 감정 분석 모델
- **모델**: Wav2Vec2 (24 Transformer 레이어)
- **데이터셋**: AIHub 대화 음성 데이터셋
- **특징 추출**: MFCC, Spectrogram
- **분류**: 7개 감정
- **정확도**: 약 60%
- **조기 종료**: Early Stopping으로 과적합 방지

#### 5. 얼굴 감정 분석 모델
- **모델**: DeepFace + MTCNN
- **기능**: 실시간 얼굴 검출 및 감정 인식
- **추가 기능**: 나이, 성별 동시 예측

- **현재 설정**: 텍스트 0.8, 음성 0.2

- 텍스트 모델의 높은 안정성을 반영하여 비중을 높게 설정

- 보다 풍부한 감정 해석 제공

**병합 공식**:
```
최종 감정 점수 = 0.8 × 텍스트 점수 + 0.2 × 음성 점수
```

**성능 향상**:
- **단일 모델 대비 12% 정확도 향상**
- 텍스트와 음성의 상호 보완적 특성 활용

</details>

## 💡 핵심 알고리즘

### 1. 멀티모달 감정 통합

```python
def multimodal_emotion_fusion(text_emotion, audio_emotion, weights=(0.8, 0.2)):
    """
    텍스트와 음성 감정을 가중치 기반으로 통합
    
    Args:
        text_emotion: 텍스트 모델 출력 확률 분포 (7차원)
        audio_emotion: 음성 모델 출력 확률 분포 (7차원)
        weights: (텍스트 가중치, 음성 가중치) = (0.8, 0.2)
    
    Returns:
        final_emotion: 최종 감정 확률 분포 (7차원)
    """
    final_emotion = (text_emotion * weights[0]) + (audio_emotion * weights[1])
    return final_emotion
```

**가중치 설정 이유:**
- **텍스트 0.8**: 높은 안정성과 정확도로 주요 역할
- **음성 0.2**: 미묘한 감정 신호 보완

```python
def update_weights(emotion, feedback, alpha=0.1):
    """
    사용자 피드백을 기반으로 감정별 가중치 업데이트
    
    Args:
        emotion: 추천된 음악의 감정 ('happy', 'sad', etc.)
        feedback: 사용자 피드백 ('yes' or 'no')
        alpha: 학습률 (기본값 0.1)
    
    Returns:
        updated_weights: 업데이트된 가중치 딕셔너리
    """
    if feedback == 'yes':
        weights[emotion] += alpha
    else:
        weights[emotion] -= alpha
    
    # 가중치를 0~1 범위로 클리핑
    weights[emotion] = max(0.0, min(1.0, weights[emotion]))
    
    # JSON 파일에 저장
    save_weights_to_json(weights)
    
    return weights
```

- **목표**: 더 정밀한 감정 분석
- **방법**:
  - 심박수, 체온 등 생체 신호 통합
  - 표정 미세 변화 추적 (마이크로 익스프레션)
  - 제스처 인식 추가
- **기대 효과**: 감정 분석 정확도 추가 향상

#### 5. 다양한 응용 분야 확장
- **정신 건강 관리**: 감정 데이터 기반 심리 상담 추천
- **버추얼 휴먼 생성**: 감정 표현하는 가상 인간 개발
- **사용자 프로파일링**: 개인화 광고/서비스 제공
- **HCI (Human-Computer Interaction)**: 감정 기반 인터페이스 개발
